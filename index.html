O que é classificação?

Analogia: é como estudar com provas antigas que têm gabarito. Na prova nova, sem gabarito, você responde sozinho com o que aprendeu.

O que entra e o que sai

Entrada
Dados e atributos do registro: números, categorias, textos
Modelo
Aprendizagem com dados rotulados
Saída
Listagem com classes correspondentes (binário ou multiclasse)
Treino
Para o treino, um histórico de dados rotulados (classificados) é necessário
Avaliação
O modelo é testado com dados e atributos padronizados, mas com valores diferentes do que recebeu
